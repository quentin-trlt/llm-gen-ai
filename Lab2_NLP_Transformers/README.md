# Lab2_NLP_Transformers

Lab 2 of the LLM & Generative AI course, in two notebooks. Lab 2.1 covers the basics of language processing on a small text corpus: tokenization, n-gram models and word and sentence embeddings. Lab 2.2 builds a small Transformer language model from scratch in PyTorch, including multi-head attention, and trains it on WikiText-2.

## How it works

### 1. Lab 2.1 – Tokenization
- Loads every `.txt` file in `docs/` into a single corpus.
- Implements character-level and word-level tokenizers by hand and plots the most frequent tokens.
- Trains a BPE subword tokenizer (`vocab_size=2000`) on the same files with Hugging Face `tokenizers`.

### 2. Lab 2.1 – N-gram modeling
- Counts n-grams with `nltk.util.ngrams` and turns the counts into next-word probability distributions.

### 3. Lab 2.1 – Embeddings
- Trains a Word2Vec model (`vector_size=200`) with gensim, saves it to `word2vec_docs.model` and plots the embeddings in 2D (PCA / t-SNE).
- Encodes sentences from the corpus with the pretrained `all-MiniLM-L6-v2` Sentence Transformer and plots them.
- Computes document embeddings with `distilbert-base-uncased` through `transformers.AutoModel`, then compares the three approaches.

### 4. Lab 2.2 – Transformer building blocks
- Implements scaled dot-product attention, multi-head attention, the position-wise feed-forward network and sinusoidal positional encoding, each with a small test case.
- Stacks them into encoder layers and a Transformer language model.

### 5. Lab 2.2 – Training and sampling
- Loads WikiText-2 (`Salesforce/wikitext`, `wikitext-2-raw-v1`) and tokenizes it with the `gpt2` tokenizer.
- Trains a small model (`d_model=128`, 4 heads, 2 layers) and generates text with temperature sampling, comparing several temperatures.

## Data & external resources

`docs/` holds the four plain-text files Lab 2.1 runs on. Any `.txt` file added there is picked up automatically. `word2vec_docs.model` is generated by Lab 2.1 and is gitignored.

The following resources are downloaded from the Hugging Face Hub on first run and cached in `~/.cache/huggingface`, so internet access is needed the first time:

| Resource | Used in |
|----------|---------|
| `sentence-transformers/all-MiniLM-L6-v2` | Lab 2.1, sentence embeddings |
| `distilbert-base-uncased` | Lab 2.1, Transformer embeddings |
| `gpt2` tokenizer | Lab 2.2, tokenization |
| `Salesforce/wikitext` (`wikitext-2-raw-v1`) | Lab 2.2, training data |
